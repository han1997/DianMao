# 启动图标重设计：爪印四象限

## 背景
现图标为"四象限方格 + 中心点"，偏素、通用。品牌名"点猫"含"点 + 猫"意象；四象限是产品核心模型。目标：把两者合成一个独特可辨识的启动图标。

## 方案（用户已选 A：爪印四象限）
- 前景 108dp vector：
  - 2×2 趾垫圆（四象限色 `#A94332` / `#795C16` / `#2D6DA8` / `#4E6D68`），位于画面上半部，全部在 66dp 安全圆内
  - 底部掌垫：主色 `#A84534` 大圆角垫形
  - 整体呼应"猫爪趾垫 = 四象限 + 掌垫 = 点"
- monochrome：同形黑色剪影
- background：保留现暖纸底不改
- 不动 manifest，不动 webp（minSdk 31，vector adaptive icon 优先）
